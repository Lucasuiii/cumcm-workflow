# AGENTS.md

Router. This file restates no rules, so the two entry points cannot drift apart.

- **Working on this repository** — read `CLAUDE.md`. It holds the layout, the invariants to preserve when editing, the test and version-bump procedure. It applies whichever agent you are; nothing in it is specific to Claude Code.
- **Using the workflow on a contest problem** — read `.agents/skills/cumcm-workflow/SKILL.md`, the canonical tree. `$cumcm-workflow` triggers it in Codex.

Adding a rule here instead of in `CLAUDE.md` is the mistake this file exists to prevent.
